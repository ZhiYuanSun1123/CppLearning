## 3. 类和对象是什么

### 3.1 类是类型设计

类用于描述一类对象具有的数据和操作。

例如一个音频片段可能具有：

```text
文件名
采样率
声道数
时长
```

以及操作：

```text
显示信息
修改时长
判断配置是否合法
```

可以定义：

```cpp
class AudioClip {
public:
    void print() const;

private:
    std::string path_;
    int sample_rate_;
    int channels_;
    double duration_seconds_;
};
```

`AudioClip` 是一个新的类型。

### 3.2 对象是类的具体实例

```cpp
AudioClip first;
AudioClip second;
```

`first` 和 `second` 是两个不同对象，各自拥有自己的成员变量。

可以理解为：

```text
类     → 设计图或类型说明
对象   → 按照该类型创建的具体实例
```

类本身不是某一段具体音频，对象才表示具体数据。

## 4. 成员变量和成员函数

```cpp
#include <iostream>
#include <string>

class AudioClip {
public:
    void set_path(const std::string& path) {
        path_ = path;
    }

    void print() const {
        std::cout << "Path: "
                  << path_
                  << '\n';
    }

private:
    std::string path_;
};

int main() {
    AudioClip clip;

    clip.set_path("speech.wav");
    clip.print();

    return 0;
}
```

其中：

```cpp
std::string path_;
```

是成员变量，每个对象都有自己的 `path_`。

```cpp
void set_path(...)
```

和：

```cpp
void print() const
```

是成员函数，用于操作对象。

## 5. `public` 和 `private`

### `public`

类外部可以访问：

```cpp
public:
    void print() const;
```

调用：

```cpp
clip.print();
```

### `private`

只有类内部成员函数可以直接访问：

```cpp
private:
    std::string path_;
```

类外不能：

```cpp
clip.path_ = "speech.wav"; // 编译错误
```

应该通过公开接口：

```cpp
clip.set_path("speech.wav");
```

这种设计称为封装：

```text
内部数据保持private
      ↓
外部通过public接口操作
      ↓
类可以检查参数并维护合法状态
```

例如：

```cpp
void set_sample_rate(int sample_rate) {
    if (sample_rate > 0) {
        sample_rate_ = sample_rate;
    }
}
```

如果成员全部公开，外部可以直接写入非法值：

```cpp
clip.sample_rate_ = -100;
```

## 6. 构造函数

构造函数在对象创建时自动调用，用来建立对象的初始状态。

特点：

- 名称与类名相同；
- 没有返回类型；
- 可以有参数；
- 可以重载；
- 创建对象时自动调用。

### 6.1 默认构造函数

不接收参数的构造函数通常称为默认构造函数：

```cpp
class AudioClip {
public:
    AudioClip() {
        path_ = "unknown";
        sample_rate_ = 16000;
    }

private:
    std::string path_;
    int sample_rate_;
};
```

创建：

```cpp
AudioClip clip;
```

此时自动调用：

```cpp
AudioClip()
```

注意：

```cpp
AudioClip clip();
```

在某些语境中会被解释成函数声明，而不是对象创建。创建默认对象写：

```cpp
AudioClip clip;
```

或者：

```cpp
AudioClip clip{};
```

### 6.2 带参数构造函数

```cpp
class AudioClip {
public:
    AudioClip(
        const std::string& path,
        int sample_rate
    ) {
        path_ = path;
        sample_rate_ = sample_rate;
    }

private:
    std::string path_;
    int sample_rate_;
};
```

创建：

```cpp
AudioClip clip("speech.wav", 16000);
```

执行过程：

```text
为clip准备存储空间
      ↓
调用AudioClip(path, sample_rate)
      ↓
成员获得初始状态
      ↓
对象可以使用
```

## 7. 构造函数重载

一个类可以有多个构造函数，只要参数列表不同。

```cpp
class AudioClip {
public:
    AudioClip()
        : path_("unknown"),
          sample_rate_(16000) {
    }

    AudioClip(
        const std::string& path,
        int sample_rate
    )
        : path_(path),
          sample_rate_(sample_rate) {
    }

private:
    std::string path_;
    int sample_rate_;
};
```

不同创建方式调用不同构造函数：

```cpp
AudioClip first;
AudioClip second("speech.wav", 48000);
```

选择关系：

```text
AudioClip first
→ 调用AudioClip()

AudioClip second("speech.wav", 48000)
→ 调用AudioClip(const std::string&, int)
```

这属于函数重载：

> 函数名相同，但参数列表不同，编译器根据实参选择匹配版本。

## 8. 成员初始化列表

成员初始化列表位于构造函数参数列表和函数体之间：

```cpp
AudioClip(
    const std::string& path,
    int sample_rate
)
    : path_(path),
      sample_rate_(sample_rate) {
}
```

结构：

```cpp
类名(构造参数)
    : 成员1(初始值),
      成员2(初始值) {
    // 构造函数体
}
```

### 8.1 初始化列表与函数体赋值的区别

函数体赋值：

```cpp
AudioClip(
    const std::string& path,
    int sample_rate
) {
    path_ = path;
    sample_rate_ = sample_rate;
}
```

可以概括为：

```text
成员先完成自身初始化
      ↓
进入构造函数体
      ↓
再执行赋值
```

初始化列表：

```cpp
AudioClip(
    const std::string& path,
    int sample_rate
)
    : path_(path),
      sample_rate_(sample_rate) {
}
```

表示：

```text
成员创建时直接使用指定初始值
```

因此构造函数通常优先使用初始化列表。

### 8.2 为什么有些成员必须使用初始化列表

`const` 成员必须在创建时初始化：

```cpp
class ModelConfig {
public:
    ModelConfig(int version)
        : version_(version) {
    }

private:
    const int version_;
};
```

下面错误：

```cpp
ModelConfig(int version) {
    version_ = version; // 编译错误
}
```

因为 `const` 对象创建后不能再赋值。

引用成员也必须通过初始化列表绑定：

```cpp
class ValueObserver {
public:
    ValueObserver(int& value)
        : value_(value) {
    }

private:
    int& value_;
};
```

引用成员属于今天的理解内容，不要求作为综合练习重点。

## 9. 成员初始化顺序

成员真正的初始化顺序取决于它们在类中的声明顺序，而不是初始化列表中的书写顺序。

```cpp
class Example {
public:
    Example()
        : second_(20),
          first_(10) {
    }

private:
    int first_;
    int second_;
};
```

真正顺序仍然是：

```text
first_
second_
```

因为声明顺序是：

```cpp
int first_;
int second_;
```

推荐把初始化列表写成相同顺序：

```cpp
Example()
    : first_(10),
      second_(20) {
}
```

这样更清楚，也能避免 `-Wreorder` 警告。

危险示例：

```cpp
class Example {
public:
    Example(int value)
        : second_(value),
          first_(second_) {
    }

private:
    int first_;
    int second_;
};
```

虽然列表先写 `second_`，但实际先初始化 `first_`。此时 `first_` 读取尚未初始化的 `second_`，存在错误风险。

正确方式之一：

```cpp
Example(int value)
    : first_(value),
      second_(value) {
}
```

必须记住：

> 成员声明顺序决定初始化顺序。

## 10. 析构函数

析构函数在对象销毁时自动调用。

特点：

- 名称是 `~类名`；
- 没有返回类型；
- 不接收参数；
- 一个类只有一个析构函数；
- 对象销毁时自动调用。

```cpp
class Trace {
public:
    Trace() {
        std::cout << "construct\n";
    }

    ~Trace() {
        std::cout << "destroy\n";
    }
};
```

使用：

```cpp
int main() {
    Trace object;
    std::cout << "inside main\n";
    return 0;
}
```

预期：

```text
construct
inside main
destroy
```

不要手动调用：

```cpp
object.~Trace();
```

局部对象会在作用域结束时自动析构，手动调用可能造成重复析构风险。

### 10.1 多个局部对象的析构顺序

```cpp
Trace first("first");
Trace second("second");
```

构造：

```text
first
second
```

析构：

```text
second
first
```

即：

> 局部对象通常按照构造的相反顺序销毁。

## 11. 栈对象和堆对象的生命周期

### 栈上的局部对象

```cpp
void process() {
    AudioClip clip("speech.wav", 16000);
}
```

离开 `process` 时自动析构。

### 堆上的对象

```cpp
AudioClip* clip =
    new AudioClip("speech.wav", 16000);

delete clip;
clip = nullptr;
```

执行：

```cpp
new AudioClip(...)
```

会调用构造函数。

执行：

```cpp
delete clip;
```

会先调用析构函数，再释放对象内存。

如果忘记：

```cpp
delete clip;
```

则对象析构函数不会按预期执行，并造成内存泄漏。

当前阶段，能使用局部对象时优先使用局部对象：

```cpp
AudioClip clip("speech.wav", 16000);
```

智能指针会在后续学习。

## 12. `const` 成员函数

成员函数参数列表后面的 `const` 表示：

> 该成员函数承诺不修改当前对象的普通成员状态。

```cpp
class AudioClip {
public:
    double duration() const {
        return duration_seconds_;
    }

private:
    double duration_seconds_;
};
```

这里：

```cpp
duration() const
```

可以读取成员，但不能直接修改：

```cpp
double duration() const {
    duration_seconds_ = 10.0; // 编译错误
    return duration_seconds_;
}
```

### 12.1 为什么需要 `const` 成员函数

```cpp
const AudioClip clip(
    "speech.wav",
    16000,
    1,
    3.5
);
```

`clip` 是 `const` 对象，只能调用不会修改对象的成员函数：

```cpp
clip.print();     // print后面有const时可以
clip.duration();  // duration后面有const时可以
```

不能调用普通修改函数：

```cpp
clip.set_duration(4.0); // 编译错误
```

### 12.2 读取函数通常应该加 `const`

例如：

```cpp
const std::string& path() const {
    return path_;
}

int sample_rate() const {
    return sample_rate_;
}

void print() const {
    // 只输出，不修改成员
}
```

修改函数不加：

```cpp
void set_duration(double duration) {
    duration_seconds_ = duration;
}
```

## 13. 普通/const成员函数重载

这一节是前面承诺补充的内容，今天需要看懂，练习中只做基础使用。

```cpp
class AudioClip {
public:
    std::string& path() {
        return path_;
    }

    const std::string& path() const {
        return path_;
    }

private:
    std::string path_;
};
```

两个函数名称和普通参数列表相同：

```cpp
path()
```

但第二个函数末尾有：

```cpp
const
```

因此它们可以构成重载。

普通对象：

```cpp
AudioClip clip;
clip.path() = "new.wav";
```

调用：

```cpp
std::string& path()
```

`const` 对象：

```cpp
const AudioClip clip;
std::cout << clip.path();
```

调用：

```cpp
const std::string& path() const
```

关系：

```text
普通对象
→ 优先使用普通版本
→ 可以返回可修改引用

const对象
→ 只能使用const版本
→ 返回只读引用
```

注意：通过可修改引用暴露内部数据可能破坏类的不变量。今天用它学习 const 重载即可，真实类通常更倾向于提供明确的修改接口。

## 14. 构造函数中的参数验证

初始化列表先完成成员初始化，然后进入构造函数体。

```cpp
class AudioClip {
public:
    AudioClip(
        const std::string& path,
        int sample_rate,
        int channels,
        double duration_seconds
    )
        : path_(path),
          sample_rate_(sample_rate),
          channels_(channels),
          duration_seconds_(duration_seconds) {
        if (path_.empty()) {
            throw std::runtime_error(
                "音频路径不能为空"
            );
        }

        if (sample_rate_ <= 0) {
            throw std::runtime_error(
                "采样率必须大于0"
            );
        }

        if (channels_ <= 0) {
            throw std::runtime_error(
                "声道数必须大于0"
            );
        }

        if (duration_seconds_ < 0.0) {
            throw std::runtime_error(
                "时长不能为负数"
            );
        }
    }

private:
    std::string path_;
    int sample_rate_;
    int channels_;
    double duration_seconds_;
};
```

构造函数的目标是：

> 构造成功的对象应当处于可使用的合法状态。

如果输入无法建立合法对象，可以抛出异常。调用者使用 `try/catch` 处理。

异常语法不是今天的考查重点。

## 18. 练习 3：把赋值改为初始化

## 25. 常见错误案例

### 错误 1：给构造函数写返回类型

错误：

```cpp
void AudioClip() {
}
```

构造函数不能写返回类型：

```cpp
AudioClip() {
}
```

### 错误 2：成员名和参数名混淆

```cpp
AudioClip(
    const std::string& path
) {
    path = path;
}
```

这里左右都是参数 `path`，成员没有被赋值。

推荐使用成员后缀：

```cpp
std::string path_;
```

然后：

```cpp
AudioClip(
    const std::string& path
)
    : path_(path) {
}
```

### 错误 3：忘记初始化基础类型成员

```cpp
class AudioClip {
public:
    AudioClip() {
    }

private:
    int sample_rate_;
};
```

`sample_rate_` 可能没有确定的有效值。

应明确初始化：

```cpp
AudioClip()
    : sample_rate_(16000) {
}
```

### 错误 4：误认为列表顺序决定初始化顺序

```cpp
private:
    int first_;
    int second_;
```

无论列表怎么写，都是先 `first_`，再 `second_`。

### 错误 5：读取函数忘记 `const`

```cpp
int sample_rate() {
    return sample_rate_;
}
```

普通对象可以调用，但 `const AudioClip` 不能调用。

如果函数不修改对象，应写：

```cpp
int sample_rate() const {
    return sample_rate_;
}
```

### 错误 6：手动调用析构函数

```cpp
clip.~AudioClip();
```

局部对象离开作用域还会再次析构，通常不应该这样做。

### 错误 7：堆对象忘记 `delete`

```cpp
AudioClip* clip =
    new AudioClip(...);

// 忘记delete
```

当前阶段优先使用局部对象。
