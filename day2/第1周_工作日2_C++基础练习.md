文件：`01_profile.cpp`

从标准输入依次读取以下信息：

- 姓名（可能包含空格）；


### 题目 10：整数位数分析

## 四、综合调试任务

下面的代码存在逻辑或类型问题。不要直接重写，先编译运行、记录现象，再逐项修复。

```cpp
#include <iostream>

int main() {
    int total = 10;
    int count = 4;
    double average = total / count;

    if (average = 2.5) {
        std::cout << "Average is 2.5\n";
    }

    for (int i = 1; i < 5; i--) {
        std::cout << i << '\n';
    }

    return 0;
}
```

需要回答：

1. `average` 为什么可能没有得到预期结果？
2. `if` 中的表达式有什么问题？
