## 2. 核心概念讲解

### 2.1 变量和地址

变量不仅有值，还存放在内存中的某个位置。这个位置可以用地址表示：

```cpp
int number = 42;

std::cout << number << '\n';   // 输出变量的值
std::cout << &number << '\n';  // 输出变量的地址
```

可以把它理解成：

```text
变量名：number
类型：int
保存的值：42
所在位置：某个内存地址
```

地址的具体数值由程序运行环境决定。不同机器、不同运行次数得到的地址可能不同，因此不要在程序中假设某个变量一定处于固定地址。

### 2.2 指针变量

指针是一种专门保存地址的变量：

```cpp
int number = 42;
int* pointer = &number;
```

这里：

- `number` 的值是 `42`；
- `&number` 是 `number` 的地址；
- `pointer` 保存 `number` 的地址；
- `*pointer` 表示访问该地址上的 `int` 对象。

观察：

```cpp
std::cout << number << '\n';    // 42
std::cout << &number << '\n';   // number 的地址
std::cout << pointer << '\n';   // 同一个地址
std::cout << *pointer << '\n';  // 42
std::cout << &pointer << '\n';  // pointer 自己也有地址
```

必须区分：

|表达式|含义|
|---|---|
|`number`|变量保存的值|
|`&number`|变量的地址|
|`pointer`|指针保存的地址|
|`*pointer`|指针指向的对象|
|`&pointer`|指针变量自身的地址|

### 2.3 通过指针修改对象

```cpp
int number = 42;
int* pointer = &number;

*pointer = 100;
```

执行后，`number` 也变成了 `100`。因为 `*pointer` 和 `number` 表示的是同一个对象。

这和引用具有相似效果：

```cpp
int& reference = number;
reference = 100;
```

区别之一是：引用在定义时必须绑定对象，而指针可以处于空状态，也可以在之后改为指向另一个对象。

### 2.4 指针的类型必须匹配

```cpp
int count = 10;
double price = 19.9;

int* count_pointer = &count;
double* price_pointer = &price;
```

`int*` 表示“指向 `int` 的指针”，`double*` 表示“指向 `double` 的指针”。类型决定了解引用时应当按照什么方式解释内存。

初学阶段不要绕过类型系统，也不要随意进行强制类型转换。

### 2.5 空指针 nullptr

当指针暂时不指向任何有效对象时，应初始化为 `nullptr`：

```cpp
int* pointer = nullptr;
```

绝对不能解引用空指针：

```cpp
int value = *pointer;  // 错误：未定义行为
```

正确做法：

```cpp
if (pointer != nullptr) {
    std::cout << *pointer << '\n';
} else {
    std::cout << "Pointer is null\n";
}
```

也可以简写为：

```cpp
if (pointer) {
    std::cout << *pointer << '\n';
}
```

建议初学阶段优先写清晰的 `pointer != nullptr`。

### 2.6 不要使用未初始化指针

错误示例：

```cpp
int* pointer;
std::cout << *pointer << '\n';
```

`pointer` 没有被初始化，它保存的地址不确定。读取或写入这个地址属于未定义行为，可能崩溃，也可能产生难以发现的错误。

安全习惯：

```cpp
int* pointer = nullptr;
```

然后只有在它指向有效对象后才解引用。

### 2.7 指针与 const

如果函数只需要通过指针读取对象，可以使用“指向 const 对象的指针”：

```cpp
void print_value(const int* pointer) {
    if (pointer != nullptr) {
        std::cout << *pointer << '\n';
    }
}
```

`const int*` 表示不能通过该指针修改所指对象：

```cpp
const int* pointer = &number;
// *pointer = 20;  // 不允许
```

今天只要求掌握：

- `int*`：可以通过指针修改所指的 `int`；
- `const int*`：只能通过指针读取所指的 `int`。

“指针本身是 const”的写法可以暂时作为了解内容：

```cpp
int* const pointer = &number;
```

这表示指针不能再指向别处，但仍可修改所指对象。今天不要求熟练使用。

### 2.8 原生数组

```cpp
int scores[5] = {80, 91, 76, 88, 95};
```

数组中包含5个相同类型的元素，下标从 `0` 开始：

```text
scores[0] → 第1个元素
scores[1] → 第2个元素
...
scores[4] → 第5个元素
```

访问 `scores[5]` 已经越界。C++原生数组不会自动检查下标是否合法。

### 2.9 数组连续存储

数组元素通常连续排列：

```cpp
for (int index = 0; index < 5; ++index) {
    std::cout << &scores[index] << '\n';
}
```

相邻地址之间的字节差通常等于 `sizeof(int)`。

注意：

- 地址看起来可能按4递增，是因为常见环境中 `sizeof(int)` 为4字节；
- 应以本机输出的 `sizeof(int)` 为准；
- 不要假定所有平台的 `int` 大小都完全相同。

### 2.10 数组名与首元素地址

在多数表达式中，数组名会转换为指向首元素的指针：

```cpp
int values[4] = {10, 20, 30, 40};
int* pointer = values;
```

此时：

```cpp
values[0] == *pointer
values[1] == *(pointer + 1)
```

但数组和指针不是同一种东西。例如在数组仍处于原作用域时：

```cpp
sizeof(values)   // 整个数组占用的字节数
sizeof(pointer)  // 一个指针自身占用的字节数
```

两者通常不同。

### 2.11 将数组传给函数

函数接收原生数组时，通常还必须接收元素数量：

```cpp
void print_array(const int* data, int size) {
    if (data == nullptr || size <= 0) {
        return;
    }

    for (int index = 0; index < size; ++index) {
        std::cout << data[index] << '\n';
    }
}
```

调用：

```cpp
int values[3] = {10, 20, 30};
print_array(values, 3);
```

指针本身不知道数组长度，因此必须由调用者提供正确的 `size`。这也是原生指针接口容易产生越界问题的原因之一。

## 3. 今日安全规则

今天写代码时必须遵守：

1. 指针声明后立即初始化；
2. 没有对象可指向时使用 `nullptr`；
3. 解引用之前确认指针非空；
4. 数组循环条件使用 `index < size`；
5. 数组和元素数量必须一起传递；
6. 只读数据优先使用 `const T*`；
7. 不猜测地址，不依赖某次运行的具体地址；
8. 今天不使用 `new`、`delete`、`malloc` 或 `free`；
9. 不故意运行已经确认会解引用空指针或越界的代码；
10. 编译时始终打开警告。

编译命令：

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic 文件.cpp -o 程序名
```
